    How this project is built and deployed

    1. Code is pushed to the main branch on GitHub.
    2. GitHub Actions builds the Docker image and pushes it to Amazon ECR.
    3. AWS SSM runs the deployment on the EC2 server (app and PostgreSQL containers).
    4. EC2, security group, ECR and IAM roles are created with Terraform.
    5. Kubernetes manifests run the app with 2 replicas on a local cluster.
    6. Prometheus scrapes /metrics and Grafana shows the graphs (Docker Compose).
